## Build Commands

```bash
make build        # Configure CMake (creates ./build)
make debug        # Configure + build Debug binary → bin/compilador
make release      # Configure + build Release binary → bin/compilador
```

Or directly with CMake:
```bash
cmake -S . -B build
cmake --build build --config Debug
```

There are no automated tests in this project.

## Architecture

This is a **C-like language IDE** written in C++17 + Qt6. It compiles and displays analysis results for a custom C-like language (not standard C). The language grammar is defined in `exp.gals` and the lexer/parser tables were generated by [GALS](https://gals.sourceforge.net/) — a Brazilian lexer/parser generator.

### Compiler Pipeline

User keypress (F5) → `MainWindow::on_actionCompilar_triggered()` → `Lexico` → `Sintatico` → display results

1. **Lexical analysis** (`src/gals/Lexico.cpp`): State-machine tokenizer driven by scanner tables in `Constants.cpp`. Produces `Token` objects (id, lexeme, line, column).
2. **Syntactic analysis** (`src/gals/Sintatico.cpp`): SLR(1) parser using tables from `Constants.cpp`. Accepts or reports a `SyntaticError`.
3. **Semantic analysis** (`src/gals/Semantico.cpp`): Currently a stub — logs action IDs but performs no checks.

### Key Source Files

| File | Role |
|------|------|
| `src/main.cpp` | Qt app init, dark purple theme stylesheet |
| `src/ide/MainWindow.cpp` | Orchestrates the full compile pipeline, file I/O, three output panels |
| `src/ide/CodeEditor.cpp` | Qt plain-text editor with line-number gutter |
| `src/gals/Lexico.cpp/h` | Tokenizer |
| `src/gals/Sintatico.cpp/h` | SLR(1) parser |
| `src/gals/Semantico.cpp/h` | Semantic stub |
| `src/gals/Constants.cpp/h` | Auto-generated scanner/parser tables — do not hand-edit |
| `src/gals/Token.h` | Token value object |
| `exp.gals` | GALS grammar specification — source of truth for the language |

### Language Supported

The compiler targets a custom C-like language (not standard C) with: `int`, `float`, `char`, `string`, `void` types; arrays; functions; `if/else`, `while`, `do-while`, `for`, `switch/case`; `read()`/`write()` I/O builtins; integer literals in decimal, hex, and binary. See `example/all.txt` for a comprehensive showcase.

### Regenerating Lexer/Parser Tables

If you modify `exp.gals`, re-run GALS to regenerate `src/gals/Constants.cpp` and `src/gals/Constants.h`. Do **not** manually edit these generated files.
